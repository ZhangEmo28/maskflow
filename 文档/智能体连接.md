# 用智能体操作 MaskFlow（MCP）

MaskFlow 提供 [MCP（Model Context Protocol）](https://modelcontextprotocol.io) 服务。把它接到 Claude、ChatGPT、Cursor 等智能体后，你只需要在网页上传图片，剩下的标注、质检、训练、评估都可以在聊天框里用一句话完成，例如：

> 帮我看看「工地」项目，把安全帽和反光衣都标出来，先标两张给我看看效果，没问题再全部标完，最后检查一下质量。

> 用 yolo11s.pt 训练 100 轮，训练完告诉我每个类别的效果，哪些类别需要补数据？

- **MCP 地址**：`https://你的域名/mcp`（本机：`http://127.0.0.1:3000/mcp`），在「账户设置 → 智能体连接」可以复制。
- **传输方式**：Streamable HTTP（无状态）。
- **认证**：Bearer 令牌，任选一种——
  - API Token（`mf_…`），在「账户设置 → API Token」创建，适合 Claude Code、Cursor 等本地客户端；
  - OAuth 2.1（授权码 + PKCE，支持动态注册），适合 ChatGPT、claude.ai 等云端连接器，连接时会跳到 MaskFlow 授权页确认。

## 连接方式

### Claude Code

```bash
claude mcp add --transport http maskflow https://你的域名/mcp --header "Authorization: Bearer mf_你的令牌"
```

也可以不加 `--header`：添加后在 Claude Code 里运行 `/mcp`，选择 maskflow 进行浏览器授权（OAuth）。

### Cursor / Windsurf / 其他支持远程 HTTP 的客户端

```json
{
  "mcpServers": {
    "maskflow": {
      "url": "https://你的域名/mcp",
      "headers": { "Authorization": "Bearer mf_你的令牌" }
    }
  }
}
```

### Claude（网页版 / 桌面版）

设置 → 连接器（Connectors）→ 添加自定义连接器，填入 MCP 地址，保存后在弹出的 MaskFlow 页面点「允许访问」。

### ChatGPT

在 ChatGPT 的连接器（应用）设置里开启开发者模式，添加自定义 MCP 连接器，填入 MCP 地址，认证选 OAuth，按提示授权（各版本菜单名称可能略有不同）。

> ChatGPT 和 Claude 网页版是从它们的云端连接你的服务器，所以 MaskFlow 必须部署在**公网 HTTPS 域名**下，并把 `.env` 中的 `MASKFLOW_PUBLIC_URL` 设成这个域名（OAuth 的签发地址和回调都依赖它）。本机或内网部署只能用 Claude Code、Cursor 这类本地客户端。

## 工具一览

| 分类 | 工具 | 说明 |
| --- | --- | --- |
| 项目 | `list_projects`、`get_project` | 项目列表与概况（标签、提示词、进度、审核状态、AI 额度、模型、训练） |
|  | `create_project`、`update_labels` | 新建项目；添加标签、设置 SAM 3 英文提示词（如 安全帽 → hard hat） |
| 图片与标注 | `list_images` | 按状态筛选：未标注（含 AI 未检出）/ 待确认（低置信度优先）/ 已确认 / 背景图 / 已驳回… |
|  | `get_annotations`、`view_image` | 读取标注；**把标注画在图上返回给智能体看**，可叠加某个模型的预测做对比 |
|  | `auto_annotate_image`、`auto_annotate_project`、`get_task` | 单张 / 批量 / 指定图片的 AI 标注（SAM 3 按标签识别、分割一切、自定义模型），批量在后台运行；没检测到目标的图片保持未标注并单独计数 |
|  | `edit_annotations` | 增、改（类别/框/多边形）、删目标，坐标为 0–1 归一化的 `[x1, y1, x2, y2]` |
|  | `confirm_annotations`、`clear_annotations`、`review_image` | 确认标注（需要用户同意）；清除所选图片的未确认结果或全部标注；团队审核的提交 / 通过 / 驳回 |
| 质量 | `check_quality` | 未分配类别、无效/极小/超大框、重复框、同一物体标了两个类别、低置信度未确认、分割缺多边形、类别过少或不平衡 |
| 训练与评估 | `check_training_data` | 训练前检查数据：最少图片数、每类在训练/验证/测试中的实际分布、类别平衡、背景图，并建议每类再补多少张什么样的图 |
|  | `list_base_weights`、`start_training`、`get_training`、`list_trainings`、`cancel_training` | 选预下载的基础权重训练（数据检查不通过会拒绝并说明原因）；查看曲线、验证/测试集指标、逐类 mAP |
|  | `view_training_plot` | 混淆矩阵、训练曲线、PR/F1 曲线、验证集「预测 vs 人工标注」对照、标签分布、训练样本 |
|  | `evaluate_model`、`list_models` | 用人工确认过的标注评估任意模型（逐类精确率/召回率/F1、错得最多的图片） |
| 数据 | `export_dataset` | 生成 YOLO / COCO / VOC / 分类裁剪数据集（在网页下载） |

## 设计约定

- **权限与网页一致**：智能体以你的身份操作，项目成员角色（所有者、审核员、标注员、只读）同样生效；看不到的项目一律返回“找不到”。
- **AI 结果默认待确认**：智能体新增或修改的目标都保存为“未确认”，只有你同意后智能体才会调用 `confirm_annotations`，“已确认”始终代表人看过。可以用「只导出/只训练已确认的目标」把关。
- **额度**：AI 标注、`view_image` 叠加模型预测、`evaluate_model` 都消耗项目所有者的每日 AI 额度（每张图 1 次）。
- **文件不经过聊天**：图片在网页上传；权重、数据集在网页下载，工具会给出页面链接。
- **令牌安全**：OAuth 访问令牌 1 小时有效，刷新令牌 30 天、每次刷新都会更换；可以在「账户设置 → 智能体连接」随时断开。API Token 可在「API Token」中撤销。服务器只保存令牌的 SHA-256。

## 自检

```bash
curl https://你的域名/.well-known/oauth-protected-resource
curl -X POST https://你的域名/mcp -H "Authorization: Bearer mf_你的令牌" \
  -H "Content-Type: application/json" -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'
```

也可以用 [MCP Inspector](https://github.com/modelcontextprotocol/inspector)（`npx @modelcontextprotocol/inspector`）连接 MCP 地址逐个试用工具。
