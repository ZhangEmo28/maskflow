# 训练权重目录

训练服务的基础权重目录（容器内 `/weights`，需要可写）。

- **推荐**：在网页「模型训练 → 基础权重」里直接下载。列出的是 Ultralytics 官方 v8.4.0 发布页的 YOLO26 / YOLO11 / YOLOv8（n/s/m/l/x，检测、`-seg` 分割、`-cls` 分类），下载后按官方文件大小和格式校验。只有管理员能下载或删除（`MASKFLOW_ADMIN_EMAILS`，未设置时为第一个注册的账号）。
- 访问 GitHub 慢时，可把 `TRAIN_WEIGHT_BASE_URL` 设为该发布页的镜像地址。
- 也可以手动把 `.pt` 放进来，训练页会列在「手动放入的权重」。任务类型按文件名识别：含 `-seg` 为分割，含 `-cls` 为分类，含 `-pose` / `-obb` 暂不支持，其余为检测。
- `.pt` 是 pickle 文件，加载即可执行代码。**只放来自可信来源的文件**；网页不接受上传 `.pt`。
- 每次训练会复制一份所用的基础权重到训练记录中（训练包里也有），所以删除这里的文件不影响已有训练。
